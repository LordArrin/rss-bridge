Trawl is a self-hosted scraping engine that bypasses JavaScript challenges and CAPTCHAs. It is a modern alternative to FlareSolverr with wider protection coverage:

  • Faster. Trawl starts with plain HTTP and only opens a browser when the site actually requires one. Repeat requests reuse the saved clearance and often complete in under a second.
  • More protections. Cloudflare, Anubis, Akamai, Imperva, DDoS-Guard, plus built-in CAPTCHA solving: Turnstile, reCAPTCHA v2, hCaptcha, GeeTest, ALTCHA.
  • Drop-in replacement. Bridges that work with FlareSolverr work with Trawl — just select it in the Proxy profile dropdown on the bridge page.

Quick start

  1. Add Trawl to your docker-compose.yml alongside RSS-Bridge (no exposed ports — it stays inside the Docker network): 
    services:
  trawl:
    image: ghcr.io/germondai/trawl:latest
    shm_size: 2gb
    environment:
      - BROWSER_POOL_SIZE=2
      - BROWSER_SESSION_MAX_ENTRIES=4
      - SESSION_CACHE_DRIVER=memory
      - SCRAPE_MAX_TIMEOUT_MS=180000
      - TIER1_TRANSPORT=bun
      - MCP_ENABLED=false
      - METRICS_DASHBOARD_ENABLED=false
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8191/health"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 30s
    restart: unless-stopped
  2. Register the proxy profile in config.ini.php: 
    [proxy_profile_trawl]
type = "Trawl"
url = "http://trawl:8191"
timeout = 180000
twocaptcha_api_key = ""
use_forward_proxy = true
forward_proxy_port = 8192
  3. Restart the stack (docker compose up -d) and select Trawl in the Proxy profile dropdown of any bridge that supports it.

Configuration options

Option Default Purpose
url — (required) Trawl address inside the Docker network
timeout 180000 Maximum time per request, in milliseconds
twocaptcha_api_key empty Optional fallback for hard CAPTCHAs (paid service)
💡 Note: The twocaptcha_api_key is validated lazily on first use. If the key turns out to be invalid or the balance is exhausted, a warning is logged and the key is ignored until the container restarts — requests keep working through Trawl's built-in solvers. Most sites do not need 2Captcha at all.
⚠️ Security: Keep Trawl on the internal Docker network without published ports. Its API has no authentication — anyone with access to it can make requests from your server's IP.

Troubleshooting

  • Trawl unavailable — the container is not running or the url is wrong. Check docker compose ps and the health status.
  • Requests succeed but feeds are empty — the site may block your server's IP entirely. Configure an upstream proxy in Trawl (PROXY_URL environment variable).
  • Timeouts on heavy sites — increase SCRAPE_MAX_TIMEOUT_MS in the compose file and timeout in config.ini.php together.
