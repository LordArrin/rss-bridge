This bridge fetches posts from Pawchive, a reliable archiving platform for creator content. It currently supports Patreon and Pixiv Fanbox creators.

  • Multi-service support. Fetches content seamlessly from all availible services using a unified interface.

  • Requires Pawchive session. You must be logged into a Pawchive account and provide your active session cookie for reliable API access.

  • Smart media handling. Options to hide videos/attachments or skip text-only posts entirely, saving bandwidth and feed clutter.

  • Automatic mirror failover. If the primary Pawchive domain is unreachable, the bridge automatically attempts to fetch data from alternative configured mirrors.

Configuration

  1. Log in to your Pawchive account: https://pawchive.pw/

  2. Open your browser's Developer Tools:
    • Windows/Linux: Press F12 or Ctrl + Shift + I
    • macOS: Press Cmd + Option + I

  3. Navigate to the Cookies storage section:
    • Google Chrome / Edge / Brave: Go to the Application tab → Expand Storage → Cookies → Select https://pawchive.pw.
    • Mozilla Firefox: Go to the Storage tab → Expand Cookies → Select https://pawchive.pw.

  4. In the cookie table, find the row where the Name is exactly session. Double-click the corresponding Value and copy the entire string.

  5. Add your session cookie to your /config/.bridges file in the [PawchiveBridge] section:

    [PawchiveBridge]
session = "your-long-session-cookie-string-here"

  6. Restart your RSS-Bridge container to apply the configuration:

    docker restart rss-bridge

⚠️ Security: Your session cookie grants full access to your Pawchive account. Never share this value with anyone. The bridge stores it securely in your local configuration and uses it only to authenticate API requests.

How authentication works

The bridge uses a stateless session cookie authentication method:

  1. On every request, the bridge attaches your session cookie to the HTTP headers.

  2. This authenticates you as a logged-in user, granting access to subscriber-only content (if your account has access) and higher API rate limits.

  3. If the primary domain fails, the bridge automatically retries the request against alternative Pawchive mirrors using the same session cookie.

Bridge parameters

Global parameters:

  • Content service: The platform to fetch from (Patreon or Pixiv Fanbox).

  • Creator ID: The numeric or alphanumeric ID of the creator (found in the URL of their Pawchive page).

  • Search query: Optional text to filter posts by title or content.

  • Limit: Maximum number of posts to fetch (default: 10).

  • Hide videos & attachments: If enabled, shows only image previews. Videos, full-size images, and file attachments will be completely hidden to save bandwidth.

  • Hide posts without media: If enabled, skips text-only posts entirely, showing only posts that contain images, videos, or files.

💡 Tip: You can find the Creator ID by looking at the URL of the creator's page on Pawchive. For example, in https://pawchive.pw/patreon/user/1234567, the Creator ID is 1234567.
