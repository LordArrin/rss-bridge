This bridge is based on the VK API. Compared to old VkBridge, this script has its own advantages and disadvantages.

  • Stability. This bridge uses the official API and does not depend on the HTML structure of VK group or user pages, which can change at any moment.
  • Requires a registered VK user. This user must obtain an access_token which is used by this script. See the "Configuration" section for details.
  • Request limits apply when caching is disabled — 5000 requests per day.

Configuration

  1. Follow this link.
  2. Authorize the my_personal_app application.
  3. You will receive a URL like https://oauth.vk.ru/blank.html#access_token=TOKEN&expires_in=0&user_id=123456. Copy the TOKEN part from this URL.
  4. Add the access_token to your config.ini.php in the Vk2Bridge section: 
    [Vk2Bridge]
access_token = "TOKEN"
💡 Note: The link in step 1 uses an application maintained by em92. You may use your own standalone application instead — just replace the client_id value in the URL with your own.
