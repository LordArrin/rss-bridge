These bridges use the GitHub REST API to fetch data from GitHub repositories. They cover issues, pull requests, releases, comments, and repository search. Compared to HTML scraping, this approach has several advantages:

  • Stability. The bridges use the official API and do not depend on GitHub's HTML structure, which can change at any moment. API endpoints are versioned and documented.
  • Smart rate limit handling. All GitHub bridges share a single GithubClient that tracks rate limits, caches rate limit states, and gracefully handles 403 / 429 responses without crashing the entire application.
  • Efficient requests. Where possible, bridges use the Events API to fetch recent PR comments in a single request instead of N separate calls per pull request.
  • Requires a Personal Access Token for heavy use. Anonymous requests are limited to 60 per hour. With a token, the limit increases to 5,000 per hour — see the "Configuration" section.

Available bridges

  • GitHub Pull Request — pull requests of a repository, or comments on a single PR, or recent PR comments across the whole project (via Events API).
  • GitHub Releases — releases of a repository with full markdown rendering, including tables, @mentions, #issue links, and embedded attachments.
  • GitHub Issues — issues via the Search API with custom query qualifiers (is:open, label:bug, sort:updated-desc, etc.).

Configuration

  1. Sign in to GitHub and open Personal access tokens in your account settings.
  2. Click Generate new token and choose classic (fine-grained tokens also work, but classic tokens are simpler for read-only access).
  3. Give the token a name (e.g. rss-bridge), set an expiration date, and leave all scopes unchecked. A token with no scopes has read-only access to public repositories — this is enough for all GitHub bridges and is the safest option.
  4. Click Generate token and copy the resulting ghp_... string. It is shown only once.
  5. Add the token to your config.ini.php under the [GitHub] section — this single token is shared by all GitHub bridges automatically: 
    [GitHub]
token = "ghp_YourTokenHere"
💡 Note: A token with no scopes is sufficient for reading public repositories and gives you 5,000 requests per hour — almost 84× more than anonymous access. Only add scopes (e.g. repo) if you need to read private repositories, which also requires the token to belong to a user with access to those repos.
⚠️ Security: Never commit your config.ini.php to git or share it publicly. The token grants read access to everything your GitHub account can see.

Rate limits

GitHub enforces the following rate limits on the REST API:

Mode Primary limit Search API
Anonymous (no token) 60 requests / hour 10 requests / minute
Authenticated 5,000 requests / hour 30 requests / minute

When a limit is reached, the GithubClient blocks further requests for one hour and throws a RateLimitException. The bridge will display a friendly error in the feed instead of crashing, and will automatically resume once the window resets.

Troubleshooting

  • Auth failed — the token in config.ini.php is invalid or expired. Generate a new one.
  • Repo not found — the repository does not exist, the owner/repo names are misspelled, or the repository is private and the token has no access to it.
  • Rate limit exceeded — the hourly quota is exhausted. Wait for the window to reset (up to 1 hour), or add a token to jump from 60 to 5,000 requests/hour.
