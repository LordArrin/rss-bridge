This bridge uses the Live Tennis API to provide tennis scores, schedules, results and fixtures for ATP, WTA, Challenger and ITF tournaments.

  • Requires an API key. The free tier allows 100 requests per day with no credit card required. See the "Configuration" section for details.
  • Stable API-based approach. Unlike HTML scraping, this bridge uses the official API and does not depend on website structure changes.
  • Real-time updates. Live matches include current scores, serving player, break points and detailed game-by-game breakdown.

Configuration

  1. Visit livetennisapi.com and sign up for a free account.
  2. Navigate to your dashboard and copy your API key.
  3. Provide the key using one of the two methods below.

Method 1: Per-request (recommended for testing)

Enter your API key in the "API Key" field when generating the feed. This key is used only for that specific request and is never stored on the server.

Method 2: Server-wide (recommended for production)

Add the API key to your config.ini.php in the LiveTennisApiBridge section:

[LiveTennisApiBridge]
api_key = "your-api-key-here"
💡 Security: Your API key is sent in the X-API-Key header, never in the query string. This keeps it out of access logs, browser history and error messages.

Request budget

The free tier allows 30 requests per minute and 100 requests per day. Each feed fetch costs exactly one API request. The default cache timeout is 900 seconds (15 minutes), so a single feed costs at most 96 requests per day regardless of how often your reader polls it.

Each distinct set of feed parameters (mode, tour, draw, player filter) is cached separately. If you subscribe to four different feed variants on one free key, you'll use four times as many requests. On the free tier, consider:

  • Subscribing to only one or two feed variants
  • Increasing the cache timeout in your feed reader
  • Upgrading to a paid plan if you need more feeds

Available feeds

  • Live matches - matches currently in play with real-time scores.
  • Today, still to start - today's scheduled matches that haven't started yet (UTC timezone).
  • Today, finished - today's completed matches — requires a paid plan.
  • Upcoming fixtures - Future scheduled matches, sorted by start time (earliest first).
⚠️ Note: The "Today, finished" feed accesses the completed-match history, which is part of the paid product. On a free key, it returns a "not included in the plan" error rather than an empty feed.

Filters

  • Tour filter: Each tour (ATP, WTA, Challenger, ITF, Juniors) covers both singles and doubles draws. Select "All tours" to see everything.
  • Draw filter: Filter by singles, doubles, or both. Team events like Davis Cup (where one event covers both singles and doubles rubbers) match neither filter.
  • Player filter: Search for matches containing a specific player's name (case-insensitive). The filter is applied after fetching results, so increase the limit if you expect matches further down the list.

Feed content

Each match appears as one item with:

  • Tournament name and round
  • Surface type (clay, hard, grass) and indoor/outdoor status
  • Match format (best of 3 or 5 sets)
  • Current status (live, completed, scheduled, etc.)
  • Set scores and game-by-game breakdown
  • Current game score and serving player
  • Break point status
  • Both players with country and current ranking (when available)
