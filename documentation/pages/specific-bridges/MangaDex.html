This bridge uses the official MangaDex API to fetch manga chapters. It provides stable, authenticated access to MangaDex content.

  • API-based. Uses the official MangaDex API instead of HTML parsing, ensuring stability even when the website layout changes.
  • Requires MangaDex account. You must have a registered MangaDex account and create a Personal Client to obtain authentication credentials.
  • Automatic token management. The bridge handles OAuth2 authentication, token refresh, and caching automatically. You never need to manually manage tokens.
  • Image fallback. When Data Saver images are unavailable (404), the bridge automatically falls back to full-quality images.

Configuration

  1. Create a MangaDex account if you don't have one: https://mangadex.org/register
  2. Log in and go to your account settings: https://mangadex.org/settings
  3. Scroll down to the API Clients section and click Create
  4. Fill in the form:
    • Name: Any descriptive name (e.g., "RSS Bridge")
    • Type: Select Personal Client
    After approval (usually automatic), your client will appear in the list.
  5. Copy your Client ID (looks like personal-client-xxxxx-xxxxx-xxxxx-xxxxx) and click Get Secret to reveal and copy your Client Secret.
  6. Add your credentials to your /config/.bridges file in the [MangaDexBridge] section: 
    [MangaDexBridge]
client_id = "personal-client-xxxxx-xxxxx-xxxxx-xxxxx"
client_secret = "your-client-secret-here"
username = "your-mangadex-username"
password = "your-mangadex-password"
log_level = "info"
  7. Restart your RSS-Bridge container to apply the configuration: 
    docker restart rss-bridge
💡 Note: The log_level parameter is optional and defaults to info. Available levels: debug, info, warning, error. Use debug for troubleshooting authentication issues.
⚠️ Security: Never share your client_secret or password with anyone. MangaDex staff will never ask for your credentials. The bridge stores them securely in your local configuration and uses them only to authenticate with the MangaDex API.

How authentication works

The bridge uses the OAuth2 password grant flow as described in the MangaDex API documentation:

  1. On first request, the bridge exchanges your username and password for an access token and a refresh token
  2. The access token is cached for 14 minutes (tokens expire after 15 minutes)
  3. When the access token expires, the bridge automatically refreshes it using the refresh token (no password needed)
  4. The refresh token is cached for 30 days. When it expires, the bridge re-authenticates with your credentials

All token management happens automatically — you never need to manually obtain, copy, or update tokens. Just configure your credentials once and the bridge handles the rest.

Bridge parameters

Global parameters:

  • Item Limit — Maximum number of chapters to fetch (default: 10)
  • Chapter Languages — Comma-separated language codes (e.g., en,jp). Leave empty for all languages.
  • Fetch chapter page images — Whether to include chapter images in feed content. Options: None (no images, fastest), Data Saver (compressed images with fallback to full quality), or Full Quality (original high-resolution images)

Title Chapters context:

  • URL to title page — Full MangaDex URL of the manga (e.g., https://mangadex.org/title/a96676e5-8ae2-425e-ba8c-0b5c0ab4a1e7/chainsaw-man)
  • Allow external feed items — Include chapters hosted on external sites

Search Chapters context:

  • Chapter Number — Filter by specific chapter number (leave empty for all)
  • Group UUID — Filter by scanlation group (from group page URL)
  • User UUID — Filter by uploader (from user page URL)
  • Allow external feed items — Include chapters hosted on external sites
💡 Tip: Authenticated requests have higher rate limits and access to more content than unauthenticated ones. If you experience "403 Forbidden" errors without credentials, configure authentication as described above.
