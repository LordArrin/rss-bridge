Installation & Setup

Quick Start with Docker

The easiest way to run RSS-Bridge is using the Docker image:

docker run -d \
  --name rss-bridge \
  -p 3000:80 \
  -v /path/to/config:/config \
  --restart unless-stopped \
  lordarrin/rss-bridge:latest

After startup, open http://localhost:3000 in your browser.

Using Docker Compose

Create a docker-compose.yml file:

services:
  rss-bridge:
    image: lordarrin/rss-bridge:latest
    container_name: rss-bridge
    ports:
      - "3000:80"
    volumes:
      - ./config:/config
    restart: unless-stopped
    deploy:
      resources:
        limits:
          memory: 1G
          cpus: '2'

Run with: docker compose up -d

Configuration Structure

  • /config.ini.php — main settings and API keys
  • /bridges-v2/ — folder for custom bridges

Setting up FlareSolverr (Cloudflare bypass)

Add the service to your docker-compose.yml:

  flaresolverr:
    image: ghcr.io/flaresolverr/flaresolverr:latest
    container_name: flaresolverr
    environment:
      - LOG_LEVEL=info
    restart: unless-stopped
    shm_size: '1gb'

Then in config.ini.php:

[proxy_profile_flaresolverr]
type = "FlareSolverr"
url = "http://flaresolverr:8191"
timeout = 60000

Performance Tips

  • Use SSD for configuration storage
  • Allocate at least 1 GB of RAM
  • Set CPU limits for stable operation

Bridge Specific Configuration

Some bridges require API keys, tokens, or cookies. Add them to config/config.ini.php. Click on a bridge to expand the instructions.

This bridge is based on the VK API. Compared to VkBridge, this script has its own advantages and disadvantages.

Advantages

  • Stability. The script does not depend on the HTML structure of VK group or user pages, which can change at any moment.

Disadvantages

  • Requires a registered VK user. This user must obtain an access_token which is used by this script. See the "Configuration" section for details.
  • Request limits apply when caching is disabled — 5000 requests per day.

Configuration

  1. Follow this link.
  2. Authorize the my_personal_app application.
  3. You will receive a URL like https://oauth.vk.com/blank.html#access_token=MNOGO_BUKAV&expires_in=0&user_id=123456. Copy the MNOGO_BUKAV part from this URL.
  4. Add the access_token to your config.ini.php in the Vk2Bridge section: 
    [Vk2Bridge]
                access_token = "MNOGO_BUKAV"
💡 Note: The link in step 1 uses an application maintained by @em92. You may use your own standalone application instead — just replace the client_id value in the URL with your own.

Developing Custom Bridges

Requirements

  • PHP 8.5+ with mandatory declare(strict_types=1)
  • Namespace RSSBridge\Bridges
  • Class must be final and extend BridgeAbstract
  • Use native \Dom\HTMLDocument instead of simple_html_dom

Minimal Bridge Template

<?php

declare(strict_types=1);

namespace RSSBridge\Bridges;

use RSSBridge\BridgeAbstract;

final class ExampleBridge extends BridgeAbstract
{
    public const NAME = 'Example Bridge';
    public const URI = 'https://example.com/';
    public const DESCRIPTION = 'Returns example content';
    public const MAINTAINER = 'yourname';
    public const CACHE_TIMEOUT = 3600;

    public function collectData(): void
    {
        $dom = getSimpleHTMLDOM(self::URI);
        $title = $dom->querySelector('h1')?->textContent ?? 'Untitled';

        $this->items[] = [
            'title'     => $title,
            'uri'       => self::URI,
            'content'   => '<p>Hello, world</p>',
            'timestamp' => time(),
            'uid'       => 'example-1',
        ];
    }
}

Required Constants

  • NAME — bridge display name
  • URI — source URL
  • DESCRIPTION — short description
  • MAINTAINER — maintainer name
  • CACHE_TIMEOUT — cache TTL in seconds

User Parameters

public const PARAMETERS = [
    '' => [
        'username' => [
            'name'     => 'Username',
            'type'     => 'text',
            'required' => true,
        ],
        'limit' => [
            'name'         => 'Item limit',
            'type'         => 'number',
            'defaultValue' => 10,
        ],
    ],
];

// Access in collectData():
$username = (string)$this->getInput('username');
$limit    = (int)($this->getInput('limit') ?: 10);

Bridge-Specific Configuration (Secrets)

For API tokens, cookies and other secrets, use the CONFIGURATION constant:

// In your bridge class:
public const CONFIGURATION = [
    'api_token' => ['required' => true],
    'session_cookie' => ['required' => false],
];

// In config/config.ini.php:
[ExampleBridge]
api_token = "your-token-here"
session_cookie = "abc123"

// Access in bridge code:
$token = $this->getOption('api_token');

Useful Functions

  • getSimpleHTMLDOM($url) — parse HTML
  • getSimpleHTMLDOMCached($url, $ttl) — cached parsing
  • getContents($url) — raw HTTP response
  • getProtectedContents($url, 'flaresolverr') — via proxy
