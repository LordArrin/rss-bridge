Установка и настройка

Быстрый старт с Docker

Самый простой способ запустить RSS-Bridge — использовать Docker образ:

docker run -d \
  --name rss-bridge \
  -p 3000:80 \
  -v /path/to/config:/config \
  --restart unless-stopped \
  lordarrin/rss-bridge:latest

После запуска откройте http://localhost:3000 в браузере.

Использование Docker Compose

Создайте файл docker-compose.yml:

services:
  rss-bridge:
    image: lordarrin/rss-bridge:latest
    container_name: rss-bridge
    ports:
      - "3000:80"
    volumes:
      - ./config:/config
    restart: unless-stopped
    deploy:
      resources:
        limits:
          memory: 1G
          cpus: '1'

Запустите: docker compose up -d

Структура конфигурации

  • config.ini.php — основные настройки и API-ключи
  • bridges-v2/ — пользовательские мосты
  • cache/ — кэш (автоматически управляется Memcached)

Настройка FlareSolverr (обход Cloudflare)

Добавьте сервис в ваш docker-compose.yml:

  flaresolverr:
    image: ghcr.io/flaresolverr/flaresolverr:latest
    container_name: flaresolverr
    environment:
      - LOG_LEVEL=info
    restart: unless-stopped
    shm_size: '1gb'

Затем в config.ini.php:

[proxy_profile_flaresolverr]
type = "FlareSolverr"
url = "http://flaresolverr:8191"
timeout = 60000

Советы по производительности

  • Используйте SSD для хранения конфигурации
  • Выделите не менее 1 ГБ оперативной памяти
  • Настройте лимиты CPU для стабильной работы

Разработка собственных мостов

Требования

  • PHP 8.5+ с обязательным declare(strict_types=1)
  • Пространство имён RSSBridge\Bridges
  • Класс final, наследует BridgeAbstract
  • Нативный \Dom\HTMLDocument вместо simple_html_dom

Минимальный шаблон

<?php

declare(strict_types=1);

namespace RSSBridge\Bridges;

use RSSBridge\BridgeAbstract;

final class ExampleBridge extends BridgeAbstract
{
    public const NAME = 'Example Bridge';
    public const URI = 'https://example.com/';
    public const DESCRIPTION = 'Returns example content';
    public const MAINTAINER = 'yourname';
    public const CACHE_TIMEOUT = 3600;

    public function collectData(): void
    {
        $dom = getSimpleHTMLDOM(self::URI);
        $title = $dom->querySelector('h1')?->textContent ?? 'Untitled';

        $this->items[] = [
            'title'     => $title,
            'uri'       => self::URI,
            'content'   => '<p>Hello, world</p>',
            'timestamp' => time(),
            'uid'       => 'example-1',
        ];
    }
}

Обязательные константы

  • NAME — название моста
  • URI — URL источника
  • DESCRIPTION — описание
  • MAINTAINER — мейнтейнер
  • CACHE_TIMEOUT — TTL кэша в секундах

Полезные функции

  • getSimpleHTMLDOM($url) — парсинг HTML
  • getSimpleHTMLDOMCached($url, $ttl) — кэшированный парсинг
  • getContents($url) — сырой HTTP-ответ
  • getProtectedContents($url, 'flaresolverr') — через прокси
